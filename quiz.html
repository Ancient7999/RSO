Basic Structure

Your JSON file must contain a root sections object. Use the Section Title as the key.

{ "sections": { "My Section Title": { "author": "Jane Smith", "questions": [ ... ] } } }

Question Object

You can provide simple lists or advanced randomization.

{ "variants": [ "What is the unit X?", "Select the correct unit X." ], "options": [ ["Sievert", "Sv"], "Gray", "Rem" ], "correct": "Sv", "explanation": "The Sievert is the SI unit...", "reward": 2 }
