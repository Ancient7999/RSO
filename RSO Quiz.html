JSON Import Guide

Basic Structure

Your JSON file must contain a root sections object. Use the Section Title as the key.

{ "sections": { "My Section Title": { "author": "Jane Smith", "questions": [ ... ] } } }

Question Object

You can provide simple lists or advanced randomization.

{ "variants": [ "What is the unit X?", "Select the correct unit X." ], "options": [ ["Sievert", "Sv"], "Gray", "Rem" ], "correct": "Sv", "hint1": "Dose equivalent weights absorbed dose by biological impact on human tissue.", "hint2": "Gray, Rem, and Sievert are all dose-related units — each used in different systems or for different quantities.", "explanation": "Sievert (Sv) is the SI unit for dose equivalent, replacing the Rem. Gray (Gy) is the SI unit for absorbed dose, replacing the Rad." }
